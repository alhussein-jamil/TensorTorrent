## Residual risks

- Activation spill serialize stays Python (`torch.save`/`load`); Rust fail-closes bare spill Evict
- CopyStore holds values only; Rust owns residency metadata on native path
- No hardware GPU validation on this machine
- VirtualBackend `max_copy_engines` still advisory (stream count formula only)
- Native dispatch tax on tiny models (~740 µs vs eager)
